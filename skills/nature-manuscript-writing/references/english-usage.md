# 英文用词、施事与句法

校一句话，先圈主语和限定动词，再依次指出谁做了什么、测到了什么、和谁比较、在哪些条件下成立。读者进入句子时应看见熟悉的对象，句尾才承载真正新增的信息。以下英文例子均为虚构示例。

## 名词和名词短语

| 检查点 | 改法与例外 |
|---|---|
| 名词是否指向可辨对象 | 把 *performance*、*quality*、*impact* 换成实际观察量，例如 *the number of particles left on the membrane*。若 *performance* 是已定义的复合终点，保留原名并说明组成。 |
| 抽象词是否掩盖动作 | *An assessment of the variation in retention was undertaken.* 可按实际操作改成 *We measured how retention varied with pore size.* 定义中的 *retention* 是必要名词，应保留。 |
| 名词串是否让读者猜关系 | *filter cycle failure rate comparison* 拆为 *a comparison of failure rates across filtration cycles*。首次出现时补上“一次循环”或“一片滤膜”才是计数单位。 |
| 可数与不可数、单复数 | *fewer failed runs*，*less drift*。先判 *data* 在该稿的用法，再统一主谓搭配。组数、样本数、重复测量次数分别命名。 |
| 冠词是否暗示已有唯一对象 | 首次介绍一般对象用 *a reference sensor*。已定义且唯一时用 *the reference sensor*。*the explanation* 暗示排除了其他解释，观察数据通常只支持 *one possible explanation*。 |
| 同概念的复用 | 不为避免重复把 *retention* 轮换成 *removal* 或 *recovery*。这些量可能有不同分子、分母或方向。技术名称可重复，叙述动词可简化。 |
| 方法名、缩写、样本名 | 首现给规范全称和实际定义，只为反复出现的术语设缩写。标题、图内标签、图注、方法和补充材料的大小写、连字符、复数形式共用一种约定。 |

## 代词、指示词与比较对象

- *It*、*they*、*their* 应能就近还原成唯一名词。*We compared the trays with the racks after they cooled.* 先核到底谁冷却，再写 *After the trays cooled, we compared them with the racks.*
- *This*、*that* 或 *these* 若指一整句，接上实义名词。*This persisted.* 改成 *The difference in drying time persisted.* 若不同条件的分母不相同，先交代分母，不能靠补一个名词掩盖差异。
- 首次引入待检现象时，不用 *this effect*、*its cause* 预设现象存在。先问 *whether the films delaminate after cooling*，观察成立后再写 *the delamination*。
- *Both*、*either*、*neither* 必须精确对应两个对象。*Each* 强调逐项，*all* 声称无例外，*on average* 允许个体不同。不能用平均差异支持 *every sample improved*。
- *Former/latter* 和 *respectively* 仅在两个短列表顺序完全一致、映射清晰时采用。跨句、跨段或超过两项时直接重写组名。先还原两个对象，再检查两个数的顺序。
- 区分限制性与补充性从句。*We excluded sensors that failed calibration* 只排除失败者。*The sensors, which failed calibration, were excluded* 将“失败”归于所有已指明的传感器。先核实际纳入标准，再定逗号。
- *We* 用于作者可负责的操作或判断，例如 *we randomized the order*。避免以 *we know* 把读者纳入未经验证的共识。*One* 和 *the reader* 通常可换成实质对象或可观察的判断。
- *Higher than* 左右应比较同一种量。*The variance of the second batch exceeded the first batch* 改为 *The variance was higher in the second batch than in the first*。*Similar* 要说清相似的是均值、形状、名次还是不确定性。

## 主语、语态、动词

| 哪一类主体 | 可写什么 | 容易写错什么 |
|---|---|---|
| 研究者或明确操作的系统 | *We sampled three regions.* / *The controller closed the valve.* | 省去执行者会掩盖谁分组、谁评分、是否盲法时，保留主动句。 |
| 被研究对象或观测到的量 | *The film contracted as it cooled.* / *The observed gap widened at higher temperatures.* | 量的变化不自动揭示变化的原因。 |
| 仪器、指标、图表 | *We measured drift with the reference sensor.* / *Figure 2 shows the paired readings.* | 指标可以有数值、图可以指引阅读。仪器和统计量不能替研究者“理解”“证实机制”或“决定样本应如何分类”。 |
| 读者需要先见到的受试对象 | *Each coupon was weighed before immersion.* | 被动语态适合操作人无关、对象连续的叙述。若谁选择样本影响偏差，就写出谁作选择。 |

以证据决定动词。描述观察用 *was higher, differed, was associated with*。*Suggested* 与 *was consistent with* 可用于保留替代解释。*Identified* 通常要求明确识别出了什么。*Established* 或 *demonstrated* 应有直接指向该主张的证据。若写 *caused, drove, led to, because of*，需说明干预、对照及仍适用的假设。随机化也不能自动解释中介机制。*Consistent with* 表示相容，不表示竞争解释已被排除。

实验动作和在本样本中获得的发现通常用过去时。已确立的定义、普遍事实、方程和图表导航可以用现在时。对未来试验用预期或条件语气。*We measured water uptake*、*uptake denotes the mass gain per unit dry mass*、*the inset shows the sampling locations* 三者时态各有理由。避免用普遍现在时将单批观察升级成一般规律。

## 形容词、副词、限定词与逻辑词

| 词类 | 具体检查 |
|---|---|
| 技术性形容词 | *paired, independent, held-out, pooled, prespecified* 只在设计确实如此时使用。若两个技术限定缺一不可，保留二者或拆句。删去 *remarkable, elegant, unprecedented* 等评价，改成可核的基线或对照。 |
| 性质形容词 | *stable, consistent, accurate, reliable, robust, efficient* 各自回答不同问题。沿时间、批次、扰动、参照物、资源中的哪一轴评估？用什么量？横跨几次？没有尺度时写具体观测。 |
| 程度与频率副词 | *clearly, markedly, strongly, substantially, largely, consistently, often* 要逐项问“多大、多少次、在哪组”。例如把 *often failed* 改成 *failed in [k] of [n] independent runs*。保留 *numerically*、*approximately* 等有实际含义的修饰词并说明近似来源。 |
| 范围和否定 | *only, even, mainly, merely, at least, up to* 放在它限定的词旁。*Only coated samples swelled* 排除了所有未涂层样本。*coated samples swelled only after heating* 限定的是时间。*Up to* 是极值，不能当典型水平。 |
| 二义连接 | 指出 *and/or* 是二者兼具、任一足够或至少一项。*Whereas* 对比同一维度，*although* 表达可解释的让步，*therefore* 要有导出结论的证据。只有时间关系时，用 *after*，不自动改成 *because*。 |
| 介词 | *By* 表示变化量，*to* 表示终值，*from … to …* 同时交代两端。*Compared with* 后面的基线就近出现。*Per* 后写清独立计数单位。*Between* 与 *within* 不可互换。 |
| 数词与量词 | *Most, some, a minority, many, few, all* 需要有分母和适用群体。已有精确计数且规模不大，直接写 *7 of 9 runs*。真实的取整、估算或检出限可以用 *approximately*、*below*。 |
| 分词与省略 | *Using a thinner membrane, the loss fell* 让 *loss* 看似选择了膜。改为 *We used a thinner membrane and observed a lower loss.* 尾部 *suggesting* 或 *demonstrating* 若提出第二个主张，独立成句并给依据。 |

## 句长、标点与平行结构

保住主语到动词的短距离。一个长句可以容纳一个比较及它不可缺少的范围、单位和基线。若含两个独立结论、两级推断或多层插入从句，先拆句。技术条件可以写得长，判断句可以很短。逐段朗读，检查读者是否在碰到谓语之前就需要回头找主语。

普通论文和评语优先完整句。减少承担主句骨架的破折号、冒号和分号。必要定义和清楚的平行关系可保留。数值范围、负号、化学名称和术语中的连字符保持数学或领域语义。句子通顺并非证据正确的判据，交稿前仍要回到实际源表及渲染图。
