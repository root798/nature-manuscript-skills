# 同一概念，只用一个名称

术语统一是让读者持续认出研究对象，不是词语美化。不为避免重复，把同一个量轮换成近义词、上位词、来源名称或代词。以下是通用编辑规则和示例，不预设任何稿件的算法、数据来源或结果。

## 先减少术语，再决定哪些需要定义

遇到一组相近名称，先判断是否真的需要多个概念。检查对象、分析层级、操作和统计量：换成同一个名称后，原来的证据是否仍在支持同一个命题？按以下情况处理，不因拼写相近就自动替换。

| 两个名称的关系 | 写作处理 |
|---|---|
| 同一对象、同一含义的别名 | 合并为作者认可且图文一致的标准名称。首次交代必要的历史名称即可，后文不轮换。 |
| 大类与具体实施 | 只有当分组比较与具体操作的区别影响发现时，才保留两个名称。在 Setup 或 Methods 用一句话说明关系；Results 按当前比较层级用词。 |
| 不同组成部分、角色或测量结果 | 保留科学区别。若某部分没有独立分析或论证职责，可以用普通动作或对象描述，不必再给它一个专门术语。 |
| 没有新增判断的上位概念 | 删除不必要的名称，直接写实际对象和操作；不要用更宽泛的词把已明确的比较再次包装。 |

合并的是文字中的同义名称，不是统计模型里的变量。不能借术语简化改变分类编码、干预定义、测量对象或分母，也不能把相关的变量写成同一个机制。

### 分类、规则与执行者的例子

在某评测研究中，若 *labelling strategy* 表示判分方式的大类，而 *grading rule* 表示实际使用的答案检查、可见信息和给分操作，两者只在需要区分这两个层级时同时保留。关系可以简述为：

> Benchmarks sharing a labelling strategy can use different grading rules.

*Scoring rule* 若在该段只是 *grading rule* 的别名，就统一；若它是已定义的数学术语，或用于区分训练选择规则和评测规则，则按实际含义保留。*Evaluation protocol* 可能还包含提示、抽样和运行预算，不能全稿替换成判分规则。*Grader* 指执行判分的人或系统，不是规则的别名；描述具体实验时，直接说谁评了什么、看到了什么、怎样给分。

这不是要求每篇稿件引入上述所有词。正文只保留理解发现所需的名称，其他机制细节可用普通语言说明。例如，在答案固定的重判实验中，“另一位评委重新给同一批答案打分”可以比“评价协议配置的干预”更清楚；若同时改变了给分标准，仍要交代这一操作，不能简化成只换了评委。

### 定义也要服从读者顺序

- 在 Setup 或 Methods 定义必要的分类关系；Results 首句直接讲发现。不要为澄清近义词，新增一段与发现无关的术语课。
- 每增加一个专门名称，说明不用它会丢失哪个比较或判断。说不出来时，优先合并、改用普通语言或移至方法。
- 没有每段术语数的固定上限。目标是让读者无需记住一串近义标签，也不会把不同对象误认成同一个。

## 先锁概念，再改句子

从当前稿件和实际渲染图提取名称。每个概念记录：**含义与分析层级、合并／保留／白话化的处理、正文标准名、图内标签、允许的短称、容易混淆的另一概念及其关系**。优先采用作者已接受、与实际计算一致的名称。图文有冲突时先核定义；不能为对齐错误标签而改变科学含义。

| 需要区分的对象 | 命名原则 |
|---|---|
| 人类偏好与人类排名 | *human preferences* 指偏好判断或相应偏好结果；*human rankings* 指由评价得到的模型顺序。报告排名相关时写排名，不能改称偏好相关。 |
| 原始判断、拟合分数、排名 | *votes*、*ratings*、*scores* 和 *rankings* 按实际对象分别命名，不能因为来自同一数据源就互换。 |
| 单项排名与汇总排名 | 类别内排名、单个评测排名和跨类别汇总排名保留各自名称。单复数及 *aggregated*、*calibrated* 等限定对应已定义的估计对象，不是修辞选项。 |
| 数据来源与测量对象 | 平台、机构或数据集名称交代来源；读者已知来源后，用测量对象承接发现。不能让来源名称轮流充当偏好、分数和排名的别名。 |
| 对象与对象之间的关系 | *agreement* 描述已明确对象之间的一致程度；给相关系数时标明哪两种排名或分数。*alignment* 不是 *ranking* 的同义词，也不自动表示相关、校准、正确性或人类效用。若使用它，须固定其实际定义。 |
| 变异与其统计量 | 名次跨度、方差、相关系数、解释方差份额各有名称及单位。不能为了统一措辞把不同统计量都叫 *variation*。 |

例如，若作者已采用 *human calibrated ranking* 和 *benchmark calibrated ranking*，就沿用这两个全称。不要在后文又称为 *human preferences*、*combined ordering* 或 *shared ability*。这只是命名示例：未采用该估计量的稿件不能因此新增 *calibrated*。

## 指代也属于术语检查

- 段首、跨段承接、比较对象切换和图号引用处优先重写标准名称。段首不能让读者回到上一段寻找 *this ranking* 或 *the other measure* 的含义。
- *it / they / their / this / these / both* 仅在就近存在唯一、同层级的对象时使用。一句话出现两种排名后，不用 *the ranking* 指其中一种。
- 短称只在术语表预先记录，并在局部上下文不会混淆时使用。缩短句子靠删冗余，不靠丢掉区分对象所需的 *human / benchmark* 等限定。
- 重复标准名可以接受；不要为了“语言丰富”重命名对象。也不要机械重复整段定义：定义一次，后续用固定名称承接。

## 正文与图共用一套名称

逐一核对标题、段首、正文、图内标签、图例、坐标轴、图注、Methods 和补充材料。图上若用短标签，在图注中建立与全称的一一映射。颜色、符号和编号不能代替对象名称。大小写可随句法位置变化，但概念限定、拼写和单复数必须保留含义。

图被冻结或不在本轮修改范围时，记录具体冲突与建议，不静默重画或把未改部分报告为已统一。完成报告说明检查和修改覆盖的范围。

例如，同一图有“每个试样在两种设置下的平均读数”和“该试样两个均值之差”。前者的标准名可用 *mean readout time*，后者用 *within-specimen difference in mean readout time*，图内短标签可写 *Difference (B − A)*。段首切换到第二个量时重提其名称和差值方向，随后检查图注能否把短标签还原成完整定义。

## 验收

1. 单读标题和段首，能认出相同对象，且比较层级没有跳换。
2. 每个关键数可对应到唯一对象、统计量和图中标签。
3. 每个代词可就近还原；两个概念不会因换词而被合并，一个概念不会被写成多个发现。
4. 全文检索旧称，逐处区分“同义漂移”与“真实不同的量”。词语扫描不能代替这一步。
5. 保留的相近术语各自承担明确的比较；其关系已在适当位置定义。删掉不必要的名称后，发现更易读，科学对象与证据层级不变。

检查器的 `avoid → preferred` 表只放已确认的替代关系。像 *human preferences* 这样在别处可能正确的词，不应设为全稿禁词；保留概念映射并人工判断具体语境。
