# 从真实问题形成研究假说

## A. 先判断发现增加了什么

有价值的发现可以揭示新的现象、限制已知规律的适用范围、区分竞争解释、建立理论结果，或证明一种方法解决了具体失败。新数据、新模型和复杂方法需要说明它们使哪项原本无法做出的判断成为可能。

先标主张类型，再定证据要求：

| 类型 | 主要证据 | 不自动支持什么 |
|---|---|---|
| 描述 | 对象与抽样明确、测量可核查、误差与范围清楚 | 因果与未观察群体推广 |
| 预测 | 设计外验证、信息时间边界、简单基线、校准或误差 | 机制与实际决策收益 |
| 因果 | 干预或明确的识别假设、可比对照、竞争解释检查 | 未研究干预与场景 |
| 理论 | 定义、假设、推导或反例；必要时数值核查 | 假设在现实中成立 |
| 方法/资源 | 明确目标、独立验收依据、对照与用途验证 | 使用次数、现实效益与训练收益 |

单一数据集可以支持有限范围的发现。跨来源检验决定推广范围；不要用“只有一个数据集”否定所有知识增量。

## B. 用现有材料回答五个问题

1. **真实任务是什么？** 谁使用结果，需要做什么决定，错判的后果是什么？
2. **现有方案默认什么？** 数据分布、标签正确性、目标一致、成本、部署条件、时间顺序等。
3. **什么条件可能失效？** 该失效应产生什么可观察结果？哪些只是猜想？
4. **实质增量是什么？** 相比默认方案和最强简单基线，新增知识、可识别对象或用途价值在哪里？
5. **什么证据能改变结论？** 正向、反向和精度不足分别意味着什么？

用一张表记录：研究问题｜现实约束｜默认条件｜待验假设｜证据路径｜当前状态。

这些问题首先由 agent 从现有记录中回答。缺口以“已知 / 推断 / 未知”标注；只有答案会影响方案选择或执行边界时才向用户提问。用户明确要引导式讨论时才采用逐轮追问；“深入思考并完成”意味着主动给出可评审的方案。

## C. 选择框架

框架的目的是让竞争解释和新增判断清楚，不是把所有量强行化成一个总分。

- **共同单位：**同一种效应确实可换算时比较其大小，交代换算假设与不确定性。
- **任务 × 规则 / 干预 × 结果矩阵：**把覆盖缺口、不可比格与交互暴露出来，不强填空格。
- **分层证据链：**现象 → 解释 → 干预 → 用途结果，每条箭头对应证据。
- **剂量或条件曲线：**识别适用边界及失效条件，防止均值遮盖条件差异。
- **多目标表示：**正确性、偏好、可靠性、成本分别报告；只有明确用途权重时才合成。

两种测量对某干预的效应比接近 1，只表示给定单位和干预下的响应关系；不能识别它们测的是同一潜在能力。高相关、同一主成分或相似排序也不单独证明能力维度。

## D. 变量是否值得分析

| 类别 | 判断 | 行动 |
|---|---|---|
| 现有数据能回答 | 测量、对照和覆盖支持所声明的描述/预测/因果问题 | 按相应证据标准分析并报告范围 |
| 重要但不可识别或精度不足 | 缺配对、缺独立标签、条件重合、来源单一或测量误差过大 | 说明缺什么及最小补强；不要先承诺方向 |
| 对当前问题无新增 | 仅是已知量的确定性换算或重复标签 | 用于表达、检查或决策成本，不另算科学发现 |

若要给干预“定价”，受控配对及共同测量尤其重要；这不是对所有描述问题的统一门槛。变量是代理不意味着必然无用，须检查其是否提供独立信息。

核查：谁有记录、谁缺失；干预类型是否与时间/家族重合；误差是否压过目标差异；分析是否改变了人群、终点或权重。

## E. 竞争解释与停止条件

经验机制假说应考虑有意义的替代解释。例如人类一致性低，可能是评分错误，也可能是评价目标不同或参照不匹配。分别列可观察预测，用改变最少条件的检验区分。纯描述主张检查测量、抽样及选择解释；理论主张检查假设、证明和反例，不强造竞争机制或现实应用。

反证后缩小或撤回主张，不把失败重新命名成成功；精度不足时记录仍无法区分。若简单基线已经解决同一问题，复杂方法须有明确新增价值，否则优先简单方案。
