# 拆论文与证据图

## 逐篇拆解

按与研究问题的距离选少数论文。每篇保留以下五部分，输出表格或要点即可；快速任务只展开决定结论所需的部分。

| 部分 | 要记录的内容 |
|---|---|
| 文献信息与问题 | 标题、作者、年份、正式版/预印本、稳定链接、要回答的问题；读过哪些节、未读哪些材料 |
| 数据与方法 | 来源、抽样/排除、单位、测量目标、关键假设、对照、统计/识别方法 |
| 主张与证据链 | 作者主张 → 观测或推导 → 对照 → 不确定性 → 成立范围；关键数逐表核对 |
| 图表与论证职责 | 相关图/表的面板、比较对象、支持哪项主张；观察到什么与作者如何解释分开 |
| 限制与可迁移性 | 作者明确限制/未来方向、分析者识别的弱点、哪些条件使其能或不能用于当前问题 |

图像未看过时写“只核对图注/正文”，不写成已核图；无图的理论工作用定义、定理与证明位置。未读补充材料不称全部证据已核。

作者限制可转述并精确定位。需要短引文时遵守可用来源的引用限额，优先一小段关键文字；不以整段复制 Limitations/Future Directions 作为流程要求。用户提供的材料与网页获取的版权材料按各自规则处理。

## 共识—分歧—候选空白

先按同一个可检验命题整理，不能只按论文主题分组。

| 类别 | 判据 | 输出 |
|---|---|---|
| 共识 | 多项相对独立证据在相近条件下支持同一命题 | 支持来源、共同范围、尚未检验的条件；综述反复引用同一数据不算独立复现 |
| 真正分歧 | 对象、终点与条件可比，结果仍不相容 | 各自证据、误差、可能原因及能区分它们的检验 |
| 表面分歧 | 目标、数据、规则、时间或估计量不同 | 说明不可直接比较及需要怎样对齐 |
| 候选空白 | 明确问题尚缺直接证据，或已知方法有已证实的适用边界 | 已查范围与日期、最近反例/相邻工作、仍未排除的研究 |

若证据没有真正冲突，就报告共同限制或验证缺口，不凑“争议”。检查数据/模型重用、同一团队衍生工作，避免虚构共识强度。

Future Directions 是作者提出的研究建议，不证明没有人做，也不证明值得做。进一步核查后续论文与相邻领域；区分未搜索、搜索未找到、已有部分解答、因数据或识别限制暂难回答。

## 从证据图走到问题

每个候选只需回答：哪条默认条件未被验证或已失效？现实后果是否重要？现有数据/方法能否区分竞争解释？最低成本的有决定力检验是什么？

保留三种证据标签：**文献直接支持 / 从文献推断 / 本项目待检验**。不能把作者的讨论句升级成实验结果，也不能用期刊级别代替证据质量。
