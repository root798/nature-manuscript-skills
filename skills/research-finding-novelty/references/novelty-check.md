## A. 原则

- **默认保留并发展用户的 idea**，不因为存在相似工作就轻易否定。
- **不只凭标题、摘要或表面相似下结论**；读核心方法、问题设定、技术细节和贡献边界。
- **不为保留 idea 而强行制造 novelty**；核心问题、关键方法、主要贡献都高度重合时停止论证。
- 判断重点是有没有明确的新增贡献和继续探索的空间，不是有没有先例。

## B. 找最接近的论文

1. 把 idea 拆成 3–5 个核心主张：研究什么问题、在什么设定下、用什么方法、得出什么、和显而易见的基线差在哪。
2. 按缺口换用同义词与相邻领域叫法检索，来源依用户和项目边界选择。记录实际检索式、范围与截止日期；快速判断不要求穷尽综述。
3. 顺着引用往前、往后各追一层：最接近论文引了谁、谁引了它。
4. 收一份按接近程度排序的名单，数量随任务缩放；链接单独一列，记年份、发表状态和核对程度。较大任务可先收 5–15 篇再深读少数；不为凑数扩展。博客和技术报告也给 URL，确实没有就写“无公开链接”或指向记录它的本地文件。

## C. 深读卡与证据图

对决定新颖性判断的论文逐篇建卡；转引旧记录时缺项写“原记录没有”，不假装已完成新的原文核查：

```text
论文：作者 年份，标题，发表状态，链接
核对程度：读过全文／读过方法与结果节／只读摘要／只见检索摘要
问题设定：他们回答什么问题，研究对象和数据是什么
核心方法：怎么做的，关键假设
技术细节：样本量、测量、对照、统计方法中与我们相关的部分
主要发现：主张—证据—对照—图表/定理位置，数字注明是否逐表核对
贡献边界：作者明确限制与未来建议；分析者发现的弱点另列
与我们的关系：同一问题／同一方法／同一结论／只是相邻
```

摘要或检索摘要里的数字，在没有核对原文表格前标"未逐表核对"。

随后按 [paper-evidence.md](paper-evidence.md) 形成共识、真实分歧、不可比结果和候选空白图。作者未来方向不等于新颖性证据；检索没有找到不等于无人做过。

## D. 差异表

| 维度 | 论文 1 | 论文 2 | … | 我们 |
|---|---|---|---|---|
| 问题 | | | | |
| 研究对象 / 数据 | | | | |
| 测量（几种、哪几种） | | | | |
| 识别方法（横截面 / 受控 / 实验） | | | | |
| 主要结论 | | | | |
| 贡献边界 | | | | |

检查核心问题、方法和主要贡献的实质重合，以及剩余差异改变了哪项科学或应用判断。换数据、实现或术语也可能实质重复；三项文字不全同不自动保留 novelty。重合明显时写清已有工作解决了什么，再判断是否仍有有意义的推进。

## E. novelty 段落怎么写

一段话，四句左右，依次回答：

1. **已有工作做到了哪里**（点名最接近的 1–3 篇，说清它们的边界）；
2. **我们具体新增了什么**（新的问题、新的测量组合、新的识别方法、新的统一解释）；写对象范围前先数样本，"同一批模型""跨厂商"要和实际重叠数一致，两侧样本不同时分开写各自的数；
3. **推进了什么**（把定性变定量、把单一测量变多测量、把相关变受控、把单个数据集变跨数据集）；
4. **为什么这个差异有意义**（它改变了什么判断、影响谁、解决了已有方法的什么不足）。

不写"首次""从未有人"，除非检索覆盖充分且能说出检索范围；更稳的写法是"据我们所知，在 X 范围内……"。

交出 novelty 段前，逐句对照自己写下的约束（区间含 0 的写法、倍数、对象范围、"首次"）再核一遍：段首声明了"不写倍数"，段内就不能有"不足一半""压掉大半"。

## F. 撞车报告

确认高度重合时，不再论证，交付：

```text
撞车对象：论文（链接、年份、状态）
重合在哪：核心问题／关键方法／主要贡献，各自引原文位置
现有差异：我们还剩哪些不同
为什么不够：这些差异为什么撑不起可信的 novelty
可以转向：保留哪部分、换成什么问题或测量后仍有空间（若有）
```

## G. 工具

- 文献检索：使用当前实际可用的文献或网页工具，优先原始论文。遵守域名和数据边界；不假定某个具名工具一定存在。不能联网时只用已有记录，注明记录日期、检索截止日和缺口。
- 读全文：使用可用的 PDF/网页阅读工具；图表判断需要看到图或明确只核了文字。不得绕过付费墙或访问控制。
- 外部意见：可以把差异表交给多模型面板挑毛病，但结论以读过原文的内容为准。
