# 候选发现、应用与闭环

卡片是研究决策材料。候选尚未验证时，标题写成待验主张，不伪装成结果。通常保留一条主线和少量备选；按需要合并字段，不以填表代替判断。应用字段用于有应用主张的研究；纯描述或理论工作标不适用并交代科学贡献，不虚构用途收益。

## 卡片模板

```text
候选：一句话说明它会改变什么认识
主张类型：描述 / 预测 / 因果 / 理论 / 方法或资源
状态与范围：已支持 / 部分支持 / 待检验 / 只是假说 / 已被反证
科学问题：已有方案的哪个默认条件，在什么任务中可能失败？
已有证据：关键结果、区间/证明、文件或原文位置；哪些只是推断？
最接近工作：它已解决什么；我们剩下的实质增量；实际核读范围
竞争解释：至少一个替代解释及其不同的可观察预测
最低必要检验：对象、对照、估计量、独立单位、精度需求与简单基线
推翻条件：什么结果会否定或实质缩小主张？精度不足又怎样处理？
应用与 impact：谁的哪个具体判断/结果会改善？重要性为何？
闭环：从发现到该应用还缺哪条证据；开发/验证如何分离？
可行性：已有/缺失数据，成本、时间依据、执行权限与依赖
位置/决定：主线 / 机制 / 备选 / Methods / 暂缓 / 停止
```

## 状态依据

| 状态 | 意义 |
|---|---|
| 已支持 | 相应类型的证据标准得到满足，明确成立范围与仍有的限制 |
| 部分支持 | 部分环节有证据，关键识别、外部验证或用途闭环尚缺 |
| 待检验 | 有具体可执行检验，尚未完成 |
| 只是假说 | 理论上合理，但现有材料不能测；指出缺失证据 |
| 已被反证 | 与关键预测不相容，且测量与精度足以作出判断 |

“区间不含 0”不是所有发现的认证门槛。理论证明、反例、等效检验和描述性结果按各自标准判断；统计显著性不能替代实质重要性。区间跨过有意义的正反效应时保留不确定，不称效果为零。

## 有应用主张时，三件事必须连起来

1. **Scientific finding：**已有证据证明什么，如何排除竞争解释，成立范围是什么？
2. **Application / impact：**这一认识改变谁的哪项决定，改善什么结果？意义与测得的收益分开。
3. **Validation loop：**如何独立验证应用确实获得这项收益？资源可复现、测量更有效、选型更好、训练获益是不同层级。

| 应用主张 | 最低必要闭环示例 |
|---|---|
| 资源可复核 | 来源与版本可追溯，标签/验收依据独立核查，重现定义一致 |
| 评价有效 | 明确目标、独立参照或可核查结果、设计外材料及适当基线 |
| 决策改善 | 固定候选和决策规则，在独立用途终点上检验错误或收益，计入成本 |
| 训练收益 | 实际训练对照及独立评价；静态候选选择不等于训练改善 |

哪些闭环是必要的取决于最终主张，不要求每个资源研究都做训练。设计草案可以说明所需实验，不能写成已登记、已执行或已成功。

## 卡片之后

按科学增量、证据可达性和影响选主线；与已有节重复的现象只作起点。必要时用审稿预演指出必须补强的环节。选题、标签、阈值及主终点若用于确认性检验，应在查看验证结果前冻结；已读过的数据保留开发身份。
